
Lab Reflection:

1. Approach:
Used a dictionary of dictionaries to store the students. The outer key is the
roll number and the value is another dictionary with Name, Branch, Semester and
a list of Marks. The menu runs in a while True loop with 7 options. 
For searching I used .get(), which returns None instead of crashing when the roll number doesn't exist. 
Delete uses pop(roll, None) so it doesn't crash on a missing roll number.
